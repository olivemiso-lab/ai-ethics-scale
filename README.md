# AI 윤리 저울

초등 4학년 눈높이의 AI 윤리 딜레마 수업 도구. 학생이 두 가치를 저울질하고(1단계), 결과와 여러 입장을 살핀 뒤(2·3단계), 다시 판단하고 멈춤 질문을 써요(4단계). 선생님 화면(`?t=1`)에서 단계를 열고 결과를 TV에 보여 줘요.

- 화면: `index.html` 하나(학생·선생님 공용). 정적 호스팅(GitHub Pages)에 올림.
- 기록: 각 선생님이 자기 구글 시트에 `Code.gs`를 붙여 넣고 웹 앱으로 배포 → 선생님 화면 '구글 시트 연결'에 주소를 넣으면 학생 기록이 그 시트로 감. 연결 전에는 연습 모드(기록은 그 기기 localStorage에만).
- 설치 안내: `setup.html` (Code.gs를 불러와 복사 단추 제공).
- 선생님 비밀번호: `Code.gs`의 `TEACHER_PIN`. 1234 그대로면 선생님 기능이 막힘.
- AI로 묶기(선택): Apps Script 스크립트 속성 `GEMINI_API_KEY`. 연습 모드에서는 안 됨.
- 딜레마 1~9는 김은경·이영준(2023)의 딜레마를 다시 쓴 것, 단계 구성은 김은경·이영준(2024) 참고(앱 바닥글에 출처).
