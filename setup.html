우리 반에서 쓰는 방법

학생 기록이 선생님의 구글 시트에 저장되도록 한 번만 연결해요. 10분쯤 걸려요. 연결하기 전에는 '연습 모드'라서 기록이 그 기기에만 남아요.

1. 구글 시트와 Apps Script 준비

  1. 구글 드라이브에서 새 스프레드시트를 만들어요. 이름은 예를 들어 'AI 윤리 저울 기록'.
  2. 시트 메뉴 확장 프로그램 → Apps Script를 열어요.
  3. 편집기에 있는 Code.gs 내용을 모두 지우고, 아래 코드 복사를 눌러 붙여 넣어요.
  4. 6번째 줄 const TEACHER_PIN = '1234';의 1234를 선생님만 아는 숫자로 바꾸고 저장해요. 1234 그대로면 선생님 화면이 열리지 않아요.

코드를 불러오는 중…

2. 웹 앱으로 배포

  1. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱을 골라요.
  2. 실행: 나, 액세스 권한: 모든 사용자로 두고 배포를 눌러요. 처음에는 권한 허용 창이 떠요(내 계정 → 고급 → 이동 → 허용).
  3. 나온 웹 앱 주소(…/exec로 끝나요)를 복사해요.

코드를 고친 뒤에는 배포 관리 → 연필 → 버전: 새 버전 → 배포로 올려요. '새 배포'를 하면 주소가 바뀌어서 학생 QR을 다시 나눠 줘야 해요.

3. 앱에 연결

  1. 선생님 화면을 열고(주소 끝 ?t=1), 아무 숫자로 들어가요(아직 연습 모드).
  2. 수업 준비 → 구글 시트 연결 칸에 2에서 복사한 주소를 붙여 넣고 연결을 눌러요.
  3. 이제 1에서 바꾼 비밀번호로 다시 들어가요. 학생 접속 주소와 QR에 연결 열쇠가 저절로 붙어요.
  4. 학생은 그 QR이나 주소로 들어와요. 이름 대신 무작위 이름이 정해져요.

(선택) AI로 멈춤 질문 묶기

선생님 화면의 'AI로 묶기'는 학생들의 멈춤 질문을 비슷한 것끼리 나눠 보여 줘요. 쓰려면 Google AI Studio에서 API 키를 만든 뒤, Apps Script 프로젝트 설정(톱니바퀴) → 스크립트 속성에 이름 GEMINI_API_KEY, 값에 키를 넣어요. 편집기에서 testGemini를 한 번 실행해 권한을 허용해요. 키가 없어도 수업은 그대로 돼요. 키는 선생님 Apps Script 안에만 있고 학생 화면에는 나가지 않아요.

개인정보

  • 학생 실명은 쓰지 않아요. 앱이 정해 주는 무작위 이름만 시트에 남아요.
  • 기록은 선생님 구글 시트에만 저장돼요. 이 사이트를 만든 사람에게는 아무것도 전송되지 않아요.
  • 학교 정책에 따라 개인 계정 시트를 써도 되는지 먼저 확인해 주세요.

딜레마 카드를 고를 때

  • 카드는 10장이에요. 딜레마 1~9는 김은경·이영준(2023)의 인공지능 윤리 딜레마를 초등 4학년 눈높이로 다시 쓴 것이에요.
  • '돌아가신 가족을 만나는 앱' 카드는 최근 가족을 잃은 학생이 있으면 다른 카드로 바꿔 주세요.
  • 한 수업에 카드 하나를 깊게 다루는 것을 권해요. 처음에는 학생과 같은 화면에서 연습 모드로 한 번 해 보세요.

문의와 의견은 틸더스 앱 페이지 댓글로 남겨 주세요.
